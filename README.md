## Deploy backend to Render

1. Go to https://render.com and sign in.
2. Create a new **Web Service** and connect your GitHub repository `mercy143/MyPortfolioWeb`.
3. When prompted for the repo root, set the **Root Directory** to `backend`.
4. Set the build command to `npm install` and the start command to `npm start`.
5. Add the following environment variables on Render:

  - `EMAIL_USER` — your Gmail address
  - `EMAIL_PASS` — app password (recommended)

6. Optionally use the provided `backend/render.yaml` for reference; it contains suggested service settings.

After the backend is deployed on Render, set the frontend `VITE_API_URL` (in your deployment or local `.env`) to point at the Render service URL so the contact form posts to the live API.
